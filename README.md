# GoBarber — Front-end

React + TypeScript front-end for **GoBarber**, a full-stack barbershop appointment scheduling application built during the **RocketSeat GoStack Bootcamp**. This project demonstrates proficiency in React, TypeScript, authentication flows, form handling, and building enterprise-grade interfaces.

## Tech Stack

- React
- TypeScript
- React Router DOM
- React Hook Form
- Axios
- Styled Components
- Unform

## Features

- User authentication (login and registration)
- Appointment scheduling interface
- User profile management
- Input validation and error handling
- Global state management
- API integration with GoBarber backend

## Getting Started

```bash
# Clone the repository
git clone https://github.com/brasileirodev/FrontendGoBarber.git
cd FrontendGoBarber

# Install dependencies
yarn

# Run the development server
yarn start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

> **Note:** This project requires the [GoBarber backend](https://github.com/brasileirodev/backend-gobarber) to be running locally.

## Project Context

GoBarber is the flagship project of the RocketSeat GoStack Bootcamp — a full-stack application involving React (web), React Native (mobile), and Node.js (backend). This repository contains the web frontend.
